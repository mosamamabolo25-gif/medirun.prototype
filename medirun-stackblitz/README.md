# MediRun — existing Figma Make project export

This is the React + Vite source export cleaned for a standalone project. Start with `npm install` then `npm run dev`.

Note: this archive preserves the exported UI/code and supporting assets. It does not automatically sync with Figma. The approved brand logo still needs to be swapped into the exported logo component if the Figma Make export did not include it as a dedicated asset.
